## 一、项目现状概览

当前管理端基于 Vite 8.1 + React 19 + TypeScript 6 + Redux Toolkit + React Router 7 + Ant Design 5 + Tailwind CSS 4 构建，聚焦"视频/评论/弹幕审核"和"用户/角色管理"的 MVP 版本。整体代码约 2300+ 行 TypeScript/TSX，12 个页面组件。
